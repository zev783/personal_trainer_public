# My private training workspace

This folder holds your personal records. When initialized at `personal/`, Git
ignores it. Keep backups in a private location.

Start with `profile/about-me.md`, `profile/goals.md`, and `schedule/current.md`.
The coach fills only what is needed. Empty folders and "not provided" fields are
valid; no sample plans are active.

Plans live in `schedule/` and `templates/`; actuals live in `logs/`.
File paths in this workspace are relative to this private folder.

Use dated filenames such as `logs/workouts/YYYY-MM-DD.md`. In folder mode,
these files are the record; a separately exported notebook is a snapshot, not
a second automatically synchronized master.
