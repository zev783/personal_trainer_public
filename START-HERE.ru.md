# Настройте персонального тренера в ChatGPT

[English](START-HERE.md) · [Краткое описание](README.ru.md)

Откройте ChatGPT и держите это руководство рядом. На настройку отведите примерно 10–15 минут, затем — время на разговор о целях. Для начала не нужно устанавливать другое приложение или покупать более дорогой тариф. Доступные функции и ограничения вашего аккаунта продолжают действовать.

**Чат** — один разговор. **Проект** объединяет разговоры с тренером, нужные файлы и инструкции. **Модель** — ИИ, который пишет ответы. **Дневник** — файл с вашим личным планом и историей.

## 1. Получите три стартовых файла

1. Откройте присланную вам страницу GitHub в браузере. Если открыт отдельный файл, вернитесь к основному списку файлов репозитория.
2. Нажмите **Code → Download ZIP**. Скачается архив с папкой; это не установка программы. Аккаунт GitHub не нужен.
3. Найдите архив в **Загрузках** на компьютере или в приложении **Файлы / Загрузки** на телефоне. Распакуйте его. В Windows нажмите на ZIP правой кнопкой и выберите **Извлечь всё / Extract All**. На телефоне нажмите на архив; если он не открывается, найдите действие «Распаковать» в меню файлов.
4. Откройте распакованную папку, затем **starter**, затем **ru**. Вам нужны три файла:

| Файл | Что с ним делать |
|---|---|
| **PROJECT-INSTRUCTIONS.txt** | Открыть и скопировать текст на шаге 3. |
| **COACH-HANDBOOK.md** | Загрузить на шаге 4. Это справочник для тренера. |
| **MY-TRAINER.md** | Загрузить на шаге 4. Это будущий личный дневник. |

`.md` — текстовый документ. Его можно загрузить, не открывая и не разбираясь в содержимом. Остальные файлы пока не нужны. Если вам уже прислали эти три пустых файла, переходите к шагу 2. Весь ZIP репозитория загружать в ChatGPT не нужно.

Внутренний справочник содержит те же английские методики и исследования, что и английская версия набора. Читать или переводить его самостоятельно не требуется: русские инструкции задают ответы и пояснения на русском языке. Пояснения в пустом дневнике тоже переведены.

## 2. Создайте личный проект

В ChatGPT откройте боковую панель или меню, найдите **Проекты / Projects**, затем **Новый проект / New project** или соседний **+**. Назовите проект **Мой персональный тренер**. Оставьте его приватным: создавать ссылку для общего доступа или приглашать участников не нужно.

Если приложение на компьютере предлагает проект с локальной папкой, для этого руководства выберите обычный проект ChatGPT с загружаемыми файлами. Если на телефоне не удаётся найти нужную кнопку, попробуйте [ChatGPT в браузере](https://chatgpt.com/) с тем же аккаунтом или вариант обычного чата ниже. Названия и доступность элементов зависят от версии приложения. [Официальное руководство по проектам](https://learn.chatgpt.com/docs/projects).

## 3. Вставьте инструкции проекта

Откройте **PROJECT-INSTRUCTIONS.txt** из `starter/ru` в приложении для просмотра текста. Выделите и скопируйте **всё содержимое**.

В новом проекте откройте меню или настройки и найдите **Инструкции проекта / Project instructions** либо **Добавить инструкции / Add instructions**. Вставьте текст и сохраните. Это отдельное поле, не строка для сообщений в чате. Откройте его ещё раз и убедитесь, что текст сохранился.

Если скачанный текстовый файл не открывается, откройте [те же русские инструкции здесь](docs/PROJECT-INSTRUCTIONS.ru.txt) в браузере и скопируйте текст файла без меню страницы.

## 4. Добавьте два файла

В разделе файлов или **Источники / Sources самого проекта** выберите **Добавить файлы / Add files**. Выберите **COACH-HANDBOOK.md** и **MY-TRAINER.md** из `starter/ru` и дождитесь окончания загрузки. Оба названия должны появиться в проекте. Прикрепление рядом с сообщением может добавить файлы только в один чат; для будущих разговоров используйте раздел файлов проекта.

Если приложение не принимает `.md`, загрузите **COACH-HANDBOOK.txt** из `starter/ru`. Для дневника сделайте обычную текстовую копию **MY-TRAINER.txt** и сообщите тренеру это название. Сохраните всё содержимое. Нужен один справочник и один актуальный дневник, без дублирующихся копий.

Устанавливать «навыки» не нужно. Справочник уже содержит методики и исследования. `agent.jsonl` — дополнительный формат тех же материалов; для начала достаточно справочника.

## 5. Выберите модель

**Наша рекомендация: для первого разговора оставьте модель по умолчанию.** Её можно сменить позже. Если возле поля сообщения есть выбор модели или регулятор **Power**, ориентируйтесь так:

| Доступный вариант | Когда мы советуем его использовать |
|---|---|
| По умолчанию / рекомендуемый | Знакомство и повседневная работа. Начните с него. |
| Faster / быстрее, менее глубокий анализ | Короткие записи и простые объяснения. |
| Smarter / глубже, более подробный анализ | Планирование недели, разбор дневника или сравнение исследований. Ответ может занять больше времени и расходовать больше лимита. |

Варианты зависят от аккаунта и этапа обновления приложения. Если выбора нет, используйте доступную модель. Не покупайте новый тариф только ради названия модели из руководства. При достижении лимита следуйте уведомлению приложения или вернитесь позже. [Официальные сведения о моделях](https://learn.chatgpt.com/docs/models).

Выбор модели не добавляет недостающие записи и не сохраняет дневник. Если есть режимы Chat и Work, для обычного общения выбирайте **Chat / Чат**; дополнительные инструменты необязательны. [Официальное руководство ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt).

## 6. Проверьте настройку и познакомьтесь с тренером

Начните новый чат **внутри проекта «Мой персональный тренер»**. Скопируйте и отправьте:

> Прочитай мой справочник тренера и MY-TRAINER.md. Сначала сообщи, какие файлы ты действительно можешь прочитать, номер версии дневника и согласован ли уже план. Если файл недоступен, сначала помоги это исправить. Затем помоги настроить моего персонального тренера. Общайся по-русски, задавай по одному вопросу, объясняй незнакомые термины и разрешай пропускать личные вопросы.

Для нового дневника ожидаются **версия 0**, настройка ещё не начата и отсутствие согласованного плана. Простое повторение названий не доказывает, что файлы прочитаны. Если тренер не может назвать эти сведения, проверьте завершение загрузки; попробуйте прикрепить файлы прямо в чат.

Отвечайте обычными словами о цели, текущей активности, свободном времени и оборудовании. Заполнять дневник самостоятельно не требуется. Тренер должен уточнить единицы измерения, часовой пояс и существенные ограничения, затем подвести итог. Учёт питания и веса необязателен; нежелательные вопросы можно пропускать.

Первый план — предложение. Если он подходит, скажите **«Используем этот план»**, иначе объясните, что изменить. Если программа от тренера уже есть, передайте её и скажите **«Помогай мне точно следовать этой программе»**. Фотографии, медицинские документы, адрес и полная дата рождения для начала не нужны.

## 7. Сохраните результат знакомства

Отправьте:

> Дай мне полный обновлённый MY-TRAINER.md как файл для скачивания. Сохрани всю прежнюю историю, включи согласованный мной план и увеличь номер версии. Если создать файл нельзя, выдай весь его текст и объясни, как сохранить.

1. Скачайте полученный файл. Проверьте план, единицы, дату и номер версии; после первого сохранения он должен быть больше 0.
2. Сохраните файл в личную папку **Мой тренер**, вне скачанного стартового набора. Оставьте резервную копию предыдущей версии.
3. Вернитесь к файлам проекта. Замените пустой **MY-TRAINER.md** сохранённой версией. Если загрузка создаёт дубликат, удалите старую копию из проекта только после сохранения резервной копии. Оставьте один актуальный дневник.
4. Откройте новый чат в проекте и спросите: **«Прочитай мой дневник. Какая у него версия и какой план сейчас действует?»** Сравните ответ с сохранённым файлом. Если тренер по-прежнему видит версию 0, исправьте загрузку, прежде чем добавлять там новые тренировки.

Если вы используете **MY-TRAINER.txt**, указывайте это название и в сообщениях. Ответ «сохранено» в чате сам по себе не доказывает изменение файла проекта. [Помощь с сохранением и восстановлением](docs/SAVING-YOUR-PROGRESS.ru.md).

## Завтра и каждую неделю

Возвращайтесь в **Мой персональный тренер** под тем же аккаунтом. Продолжайте чат или создайте новый внутри проекта. Например:

- «Какая у меня сегодня согласованная тренировка? Объясни упражнения».
- «Сделал два подхода по восемь повторений, по 10 кг в каждой руке».
- «Исправь запись: во втором подходе было шесть повторений».
- «Подведи итоги недели: что записано, чего не хватает и какие изменения ты предлагаешь».

Можно писать обычным языком или использовать голос, если он доступен. Проверяйте распознанные числа и единицы. В конце каждого занятия повторяйте шаг 7 для сохранения дневника. Тренировка в расписании считается выполненной только после вашего сообщения.

## Если что-то не получается

| Проблема | Следующий шаг |
|---|---|
| Нет Projects или поля инструкций | Обновите приложение или попробуйте браузер с тем же аккаунтом. Если функции нет, используйте обычный сохраняемый чат: вставьте инструкции первым сообщением, приложите справочник и актуальный дневник. Повторяйте для каждого нового чата. |
| Тренер снова задаёт вопросы знакомства | Попросите сначала прочитать актуальный дневник. Проверьте версию файла в проекте. |
| Ответ непонятен | Скажите «Объясни проще, по одному шагу». |
| Ссылка на скачивание истекла или файла нет | Попросите создать файл заново или выдать полный текст дневника. См. руководство по сохранению. |
| Достигнут лимит загрузок | Оставьте в проекте справочник и актуальный дневник. Старые копии храните отдельно; следуйте уведомлению о лимите аккаунта. |

Если прикрепить файлы вообще нельзя, тренер пока не сможет использовать полный набор. Общие вопросы задавать можно, но для надёжного ведения истории сначала попробуйте браузер или решите проблему загрузки.

## Если вы используете Claude

Создайте личный проект Claude, вставьте **starter/ru/PROJECT-INSTRUCTIONS.txt** в инструкции проекта и загрузите **starter/ru/CLAUDE.md** и **starter/ru/MY-TRAINER.md**. Нужен большой файл `CLAUDE.md` из `starter/ru`, а не короткий файл в корне репозитория. Оставьте модель Claude по умолчанию, затем выполните шаги 6 и 7 и следуйте тому же ежедневному порядку. [Официальное руководство Claude](https://support.claude.com/en/articles/9517075-what-are-projects).

## Дополнительные возможности — позже

Когда основная настройка заработает, попробуйте «Изучи этот вопрос и покажи источники». Проверка актуальных исследований требует доступа к интернет-поиску; тренер должен сообщить, если не может проверить источники. Расчётные отчёты, навыки Claude и локальные папки описаны в [дополнительных возможностях](docs/ADVANCED-OPTIONS.ru.md). Для первой недели они не нужны.

Формулировки интерфейса и сведения о выборе модели проверены **2026-09-22**. Это руководство не подтверждает доступность функций именно в вашем аккаунте.
