# Set up your personal trainer in ChatGPT

[По-русски](START-HERE.ru.md) · [Back to the overview](README.md)

Have ChatGPT open and keep this guide beside it. Allow about 10–15 minutes for setup, then a conversation about your goals. You do not need to install another app or buy an upgrade before trying this. Your account's normal features and limits still apply.

A **chat** is one conversation. A **project** groups your trainer chats with the files and instructions they need. A **model** is the AI that writes the replies. A **notebook** is the file that holds your personal plan and history.

## 1. Get the three starter files

1. Open the GitHub page someone shared with you in a web browser. If you are viewing an individual file, go back to the repository's main file list.
2. Select **Code → Download ZIP**. This downloads a compressed folder; it does not install software. You do not need a GitHub account.
3. Find it in **Downloads** on a computer, or the **Files / Downloads** area on your phone. Extract or unzip it. On Windows, right-click the ZIP and choose **Extract All**. On a phone, use the file app's extract/uncompress action if tapping the ZIP does not open it.
4. Open the extracted folder, then open **starter**. Use these three files:

| File | What to do with it |
|---|---|
| **PROJECT-INSTRUCTIONS.txt** | Open it and copy the text in step 3. |
| **COACH-HANDBOOK.md** | Upload this in step 4. This is the coach's reference. |
| **MY-TRAINER.md** | Upload this in step 4. This blank diary will become your own record. |

`.md` is a text document. You can upload it without opening or understanding it. Leave the other files alone for now. If someone already sent you these three blank files, start at step 2. Do not upload the whole repository ZIP.

## 2. Create your private project

Open ChatGPT's sidebar or menu, find **Projects**, and choose **New project** or the nearby **+**. Name it **My Personal Trainer**. Keep it private; you do not need a share link or collaborators.

If the desktop app offers a local-folder project, choose a regular ChatGPT project for this guide. It uses uploaded files. If you cannot find a control on your phone, try [ChatGPT in a browser](https://chatgpt.com/) with the same account, or use the normal-chat fallback below. Labels and availability vary by app version. [Official project guide](https://learn.chatgpt.com/docs/projects).

## 3. Paste the project instructions

Open **PROJECT-INSTRUCTIONS.txt** from `starter` in a text viewer. Select and copy **all of its contents**.

Inside your new project, open its menu or settings and look for **Project instructions** or **Add instructions**. Paste the text there and save. This is separate from the message box where you chat. Reopen it once to check the text was saved.

If you cannot open the downloaded text file, view [the same instructions here](docs/PROJECT-INSTRUCTIONS.txt) in your browser and copy the file's text, without the page menus.

## 4. Add the two files

In the **project's** files or **Sources** area, choose **Add files**, select **COACH-HANDBOOK.md** and **MY-TRAINER.md** from `starter`, and wait for the uploads to finish. You should see both names in the project. Adding them only beside a message may attach them to that one chat; use the project's file area for future chats.

If `.md` is rejected, upload **COACH-HANDBOOK.txt** from `starter` instead. For the notebook, make a plain-text copy called **MY-TRAINER.txt** and tell the coach you are using that name. Keep its contents intact. Use one handbook and one active notebook, not several copies of each.

You do not have to install skills. The handbook already contains the coaching workflows and research. `agent.jsonl` is an optional alternative containing the same material; beginners can use the handbook.

## 5. Choose a model

**Our recommendation: keep the default model for your first conversation.** You can change it later. If you see a model or **Power** control near the message box, use this guide:

| Choice available in your app | Our suggested use |
|---|---|
| Default / recommended | Setup and everyday coaching. Start here. |
| Faster / lighter reasoning | Quick logs and simple explanations. |
| Smarter / deeper reasoning | Planning a week, reviewing records, or comparing research. Expect a longer wait and more usage. |

Available choices vary by account and rollout. If no selector appears, continue with what your app provides. Do not buy an upgrade just to match a model name in a guide. If you reach a usage limit, follow the app's notice or return later. [Official model guidance](https://learn.chatgpt.com/docs/models).

Model choice does not supply missing records or save your notebook. Use ordinary **Chat** if your app offers Chat and Work modes; advanced tools are optional. [Official ChatGPT guide](https://learn.chatgpt.com/docs/use-chatgpt).

## 6. Check the setup and meet your coach

Start a new chat **inside My Personal Trainer**. Copy and send:

> Read my coaching handbook and MY-TRAINER.md. Before we begin, tell me which files you can actually read, my notebook revision, and whether a plan is already agreed. If a file is missing, help me fix that first. Then help me set up my personal trainer. Ask one question at a time, explain unfamiliar terms, and let me skip personal questions.

For a fresh notebook, expect **revision 0**, setup not started, and no agreed plan. Merely repeating filenames does not prove they were read. If the coach cannot give those details, check that both files finished uploading; try attaching them directly to the chat.

Answer naturally about your goal, current activity, available time, and equipment. You do not need to fill in the notebook yourself. The coach should ask about units, time zone, and relevant limitations, then summarize your answers. Food and weight tracking are optional; skip questions you do not want to answer.

The first plan is a draft. Say **“Use this plan”** when it fits, or explain what to change. If you already have a coach's program, provide it and say **“Help me follow this exactly.”** You do not need to share photos, medical documents, your address, or full birth date.

## 7. Save your starting point

Send:

> Give me my complete updated MY-TRAINER.md as a downloadable file. Keep all existing history, include the plan I agreed to, and increase the revision number. If you cannot create a file, give me its complete text and explain how to save it.

1. Download the returned file. Check the plan, units, date, and revision; a fresh saved notebook should be above revision 0.
2. Save it in your own private **My Trainer** folder, outside the downloaded starter. Keep a backup of the previous version.
3. Return to the project's files. Replace the blank **MY-TRAINER.md** with your saved version. If uploading adds a duplicate, remove the old project copy only after you have saved a backup. Keep one active notebook.
4. Open a fresh chat in the project and ask: **“Read my notebook. What are its revision and active plan?”** Check that the answer matches the file you just saved. If it still sees revision 0, fix the project upload before logging more activity there.

If you use **MY-TRAINER.txt**, use that name in these messages too. A “saved” reply in a chat is not proof that the project file changed. [Saving and recovery help](docs/SAVING-YOUR-PROGRESS.md).

## Tomorrow, and each week

Return to **My Personal Trainer** in the same account. Continue the chat or start one inside that project. Try:

- “What is my agreed workout today? Explain the exercises.”
- “I finished two sets of eight, with 10 kg in each hand.”
- “Correct that entry: it was six repetitions in the second set.”
- “Review my week. Show what is recorded, what is missing, and suggested changes.”

Use ordinary language or voice if available. Check voice-transcribed numbers and units. At the end of each session, repeat step 7 to save the updated notebook. A workout on the schedule does not count as completed until you report it.

## If you get stuck

| Problem | Next step |
|---|---|
| No Projects option or instructions field | Update the app or try the browser with the same account. If unavailable, use a normal saved chat: paste the instructions as the first message and attach the handbook and latest notebook. Repeat for every new chat. |
| The coach asks setup questions again | Ask it to read your latest notebook first. Check the project's file revision. |
| The answer is confusing | Say “Explain that more simply, one step at a time.” |
| The download link expired or no file appeared | Ask for a fresh file or complete notebook text. See the saving guide. |
| Upload limit reached | Keep just the handbook and latest notebook in the project. Save older backups privately; follow any account limit notice. |

If you cannot attach files at all, the coach cannot use the full starter yet. You can ask general questions, but try the browser or resolve the upload issue before relying on this setup to preserve your training history.

## If you use Claude

Create a private Claude Project, paste **starter/PROJECT-INSTRUCTIONS.txt** into its project instructions, and upload **starter/CLAUDE.md** and **starter/MY-TRAINER.md**. Use the large `CLAUDE.md` inside `starter`, not the short file at the repository root. Use Claude's default model, then follow steps 6 and 7 and the same daily routine. [Official Claude project guide](https://support.claude.com/en/articles/9517075-what-are-projects).

## Optional extras, later

Once the basic setup works, ask “Research this question and show your sources.” Current research requires browsing; the coach should say when it cannot check sources. Calculated audits, optional Claude skills, and local folders are explained in [advanced options](docs/ADVANCED-OPTIONS.md). They are not needed for your first week.
