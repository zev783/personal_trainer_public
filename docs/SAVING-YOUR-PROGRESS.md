# Save your progress and continue tomorrow

[По-русски](SAVING-YOUR-PROGRESS.ru.md) · [Setup guide](../START-HERE.md)

Your handbook is the coaching reference. **MY-TRAINER.md** is your personal diary. Updating a conversation does not necessarily update the diary stored in your project.

## Save after a session

1. Ask: **“Give me my complete updated MY-TRAINER.md. Preserve all history and increase the revision number.”**
2. Open the file or text it returns. Check the revision, date, units, agreed plan, and newly recorded activity.
3. Download it to your private **My Trainer** folder, outside the starter. Save the previous version as a backup, for example in a separate dated folder.
4. In the project's files or Sources area, replace the old notebook with the new one. If both appear, remove the old project copy after backing it up. Keep only one current notebook in the project.
5. In a fresh project chat, ask: **“Read my notebook and tell me its revision and active plan.”** Check against the saved file. If it reads the old revision, check the uploaded files before adding new records.

Until this is done, the newest details may exist only in the conversation. Ask the coach whether it has recorded something in the chat, prepared a file for download, or actually changed a file using an available tool.

## If you cannot download a file

Ask: **“Show the entire updated notebook in one text block, with no missing history.”** Copy the contents of that block into a plain-text editor, such as Notepad, and save them privately. Use UTF-8 text if an encoding choice appears.

Keep the name **MY-TRAINER.md**, or use **MY-TRAINER.txt** if your device makes that easier. Tell the coach which filename you use, and keep using it. Do not save only the coach's brief summary or a screenshot. On a phone without a suitable text editor, try the browser on a computer or ask the coach to generate a fresh downloadable file. Keep the existing notebook until the full replacement is saved.

If a link expires, ask for a fresh download. If the coach says it cannot see older entries, supply your last complete saved notebook before it creates a replacement.

## A new chat, device, or app

For another chat in the same project, start inside that project and verify the notebook version. On another device, sign in with the same account and look for the project; if it is unavailable there, use the browser or set up a new private project from your saved files.

For another app, add the coaching file and latest notebook, paste the project instructions, and send:

> Continue from this notebook. Tell me its revision, last updated date, and active plan before we continue. Do not restart onboarding for information already present.

For Russian coaching use the files in `starter/ru`. For a Claude Project use that language's `CLAUDE.md` as the coaching file. Transfer your current personal notebook, never replace it with the blank download.

## Conflicting copies or longer histories

If two notebooks disagree, give the coach both privately and ask it to reconcile them without losing history. A newer timestamp alone does not establish that a changed plan was agreed.

If the notebook becomes too large, ask for an archive proposal. Preserve the original records separately before agreeing to shorten the active notebook. List archive filenames in the notebook and say which are attached. An unseen archive cannot support a detailed review.

## Folder mode

An assistant with actual local file access can save records into a private workspace. See [folder mode](FOLDER-MODE.md). Choose one main record and reconcile versions before switching modes. An ordinary project upload does not give the assistant access to your computer.
