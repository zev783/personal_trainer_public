# Ответы на вопросы

[English](FAQ.md) · [Настройка](../START-HERE.ru.md)

**Нужно другое приложение, платный тариф, аккаунт GitHub или навыки ИИ?**

Начните с вашего аккаунта ChatGPT. Попробуйте доступные проекты и загрузки, прежде чем думать о новом тарифе; лимиты могут различаться. Скачать публичный набор можно без аккаунта GitHub. Установка навыков и выполнение кода необязательны.

**Какую модель выбрать?**

Начните с модели по умолчанию. Для подробного разбора или планирования можно выбрать более глубокий анализ, если он доступен. Краткое сравнение есть в шаге 5 [руководства](../START-HERE.ru.md). Определённое название модели для начала не требуется.

**Достаточно вставить ссылку GitHub?**

Ссылка сама по себе не устанавливает тренера и не гарантирует чтение всех файлов. Следуйте руководству: вставьте инструкции проекта и загрузите один справочник и дневник.

**Инструкции и файлы добавляются в одно место?**

Текст PROJECT-INSTRUCTIONS.txt вставляется в поле инструкций проекта. Справочник и дневник загружаются в файлы или Sources проекта. Затем начинайте разговор внутри проекта. В обычном чате инструкции нужно отправить сообщением и прикрепить оба файла для этого разговора.

**Зачем нужен agent.jsonl?**

Это другой формат того же справочника. Для начала используйте COACH-HANDBOOK.md или копию .txt. JSONL не включает инструкции автоматически. Для работы Codex с репозиторием предназначен AGENTS.md.

**Какой файл Claude выбрать?**

Для английского проекта Claude используйте starter/CLAUDE.md, для русского — starter/ru/CLAUDE.md. Также вставьте инструкции из той же папки и загрузите актуальный дневник. Короткий CLAUDE.md в корне предназначен для Claude Code. См. [дополнительные возможности](ADVANCED-OPTIONS.ru.md).

**Тренер всё запомнит?**

Храните сохранённый дневник и резервную копию. После занятия скачайте полную обновлённую версию и замените файл проекта. Попросите новый чат проекта прочитать номер версии. См. [сохранение и восстановление](SAVING-YOUR-PROGRESS.ru.md).

**Что делать, если загрузка или скачивание не работают?**

Попробуйте браузер с тем же аккаунтом. Если Markdown не принимается, используйте готовый COACH-HANDBOOK.txt и текстовый дневник MY-TRAINER.txt. Если ссылка истекла, попросите новый файл или полный текст. Краткое резюме не заменяет дневник. Следуйте уведомлению о лимитах аккаунта.

**Что значит «план принят» или adopted?**

Вы согласились использовать план. Черновик — только предложение. Сообщение о выполненной тренировке само по себе не меняет план.

**Можно без калорий и взвешиваний? Можно со своей программой?**

Да. Сообщите тренеру предпочтения. Если программа уже есть, укажите источник и даты и скажите, хотите ли точно ей следовать. Тренер должен сохранять программу, отделяя предложения от действующих указаний.

**Могут два человека пользоваться одним проектом?**

Для каждого создайте отдельный личный проект и дневник. Делитесь ссылкой на пустой набор, а не заполненным дневником.

**Что делать при ошибке тренера?**

Исправьте прямо: «Это было по 10 кг в каждой руке, а не 10 кг всего». Попросите исправить исходную запись и зависимые итоги. Проверьте файл перед сохранением.

**Можно пользоваться русской версией без знания английского?**

Для настройки и повседневного общения — да: используйте русское руководство и файлы starter/ru. Тренер объясняет общие английские материалы по-русски. Часть служебных заголовков остаётся английской для инструментов анализа; заполнять их самостоятельно не нужно. Внутренняя библиотека исследований общая, без отдельного перевода.

**Есть автоматическая синхронизация часов, полная база упражнений или гарантированный анализ здоровья?**

Нет. Вы сообщаете об активности или выборочно передаёте свои выгрузки. Анализ веса оценивает тенденцию показаний весов по записанным измерениям при указанных допущениях; он не измеряет жировую массу и не ставит диагнозы.

**Исследования всегда актуальны?**

Нет. У обзоров есть источники и даты проверки. При необходимости просите обновление. Для проверки актуальных источников помощнику нужен интернет-поиск; исследование не меняет план автоматически.
