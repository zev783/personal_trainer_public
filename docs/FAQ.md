# Common questions

[По-русски](FAQ.ru.md) · [Setup guide](../START-HERE.md)

**Do I need another app, a paid upgrade, GitHub account, or skills?**

Start with the ChatGPT account you already have. Try its available project and upload features before considering an upgrade; limits vary. You can download this public starter without a GitHub account. Installing skills or running code is optional.

**Which model should I choose?**

Start with the app's default. For a detailed review or planning conversation, consider its deeper reasoning option if available. Use the short comparison in [step 5](../START-HERE.md#5-choose-a-model). You do not need a particular model name to begin.

**Can I paste the GitHub URL and be done?**

A link alone does not install the coach or guarantee access to all files. Follow the setup guide: paste project instructions and upload one coaching file plus your notebook.

**Do instructions and files go in the same place?**

Paste the contents of PROJECT-INSTRUCTIONS.txt into the project's instructions field. Upload the handbook and notebook to the project's files or Sources. Then start a conversation in the project. If using a normal chat instead, paste the instructions as a message and attach both files for that chat.

**What is agent.jsonl for?**

It is an alternative format of the same coaching reference. Beginners should use COACH-HANDBOOK.md or its .txt copy. JSONL does not automatically activate instructions. Codex repository instructions use AGENTS.md.

**Which Claude file should I use?**

Use starter/CLAUDE.md for an English Claude Project or starter/ru/CLAUDE.md for Russian. Also paste that folder's project instructions and upload your current notebook. The short root CLAUDE.md is for Claude Code. See [advanced options](ADVANCED-OPTIONS.md).

**Will it remember everything?**

Keep a saved notebook and backup. After a session, download the full update and replace the project copy. Ask a fresh project chat to read its revision. See [saving and recovery](SAVING-YOUR-PROGRESS.md).

**What if uploads or downloads fail?**

Try the browser with the same account. Use the provided COACH-HANDBOOK.txt if Markdown is rejected, and a plain-text MY-TRAINER.txt for the diary. If a download expires, request a new file or the complete text. Do not substitute a short summary for your diary. Follow any account limit notice.

**What does “adopted” mean?**

You agreed to use a plan. A draft is a suggestion. Reporting a workout does not automatically change your plan.

**Can I skip calorie counting or weigh-ins, or bring an existing program?**

Yes. Tell the coach your preferences. If bringing a program, give its source and dates and say whether you want to follow it exactly. It should preserve the program and keep suggestions separate.

**Can two people share one project?**

Give each person a separate private project and notebook. Share the blank starter link, not your filled-in diary.

**What if the coach gets something wrong?**

Correct it directly: “That was 10 kg per hand, not 10 kg total.” Ask it to correct the original entry and affected totals. Review the file before saving it.

**Can I use the Russian version without reading English?**

Yes for setup and everyday coaching: use the Russian guide and starter/ru files. The coach explains the shared English references in Russian. Some technical headings stay English for the analysis tools; you do not need to fill them in yourself. The internal research library is shared, not separately translated.

**Is there automatic wearable sync, a full exercise database, or guaranteed health analysis?**

No. You report activity or selectively provide exports. Weight analysis estimates a scale trend from recorded measurements under documented assumptions; it does not measure body fat or diagnose health conditions.

**Is the research always up to date?**

No. Briefs have sources and checked dates. Ask for a current refresh when needed. The assistant must have browsing to verify current sources, and research does not automatically change your plan.
