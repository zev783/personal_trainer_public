# Port coverage and deliberate changes

The public kit generalizes the reusable methods without carrying over an individual's profile, health records, training block, nutrition targets, log history, product database, or uncited private research reports.

| Capability | Public implementation |
|---|---|
| Exact adopted-plan execution and scoped changes | Core and daily skills, complete weekly templates, version/hash guidance |
| Live set logging, corrections, and saved cues | Daily skill and generic observation rules |
| Percentage/effort-based load reconciliation | Workload and loads reference; no fabricated tested maximums |
| Rolling workload and projections | Non-overlapping structured segments; modality/category/evidence totals; required baseline and separate optional scenarios |
| Zone and event-specific accounting | Explicit zone minutes plus unclassified remainder; user-chosen rules; event exposure kept as an overlapping axis |
| Food facts, target authority, and incomplete intake | Nutrition skill/reference, source-specific facts, effective target versions, complete-day averages |
| Weekly audit and report format | Executable read-only audit plus detailed source-review/report instructions |
| Condition-aware weight model | Monte Carlo condition adjustment, per-date aggregation, Bayesian linear trend, uncertainty intervals, optional justified prior |
| Research and refreshed evidence | Research skill, seven prompts, six source-linked topic briefs, private note/index/source templates |
| Supplied-source preservation | Exact source bytes, SHA-256, provenance note, no automatic verification or plan adoption |
| Beginner use and portability | English/Russian walkthroughs, model-choice guidance, notebook mode, readable handbook with text fallback, optional JSONL, Claude Project file, native Claude packages, optional tools and folder mode |

The analysis code was adapted to explicit selected inputs, kg/lb support, generic visible assumptions, and portable standard-library execution. It is a methodological port, not a promise of bit-for-bit agreement with previous athlete-specific outputs. The weight reference convention and some condition priors are generalized and documented. No fixed race category, weekly training-hour target, calorie deficit, station exclusion, or zone allocation is preselected.

Narrative records remain readable, but numerical audit totals require documented structured summaries with provenance. The assistant can prepare those summaries from actual records; the scripts do not claim to understand arbitrary prose. Source parsing and model tests establish computational behavior, not clinical validation or guaranteed model instruction-following.

The research library contains new generic summaries of checked sources. Private reports and their uncited numerical claims were not published. Abstract-only checks are labeled; this seed library is not an exhaustive or continuously updated review.

No automatic wearable sync, cloud persistence, background training adjustment, or automatic benchmark publisher is included. Ordinary chat still uses explicit notebook saving. Real app onboarding, browsing availability, and execution permissions depend on the actual session and need manual validation there.
