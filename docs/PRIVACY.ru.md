# Ваши данные под вашим контролем

[English](PRIVACY.md)

Делитесь ссылкой на пустой репозиторий. Не публикуйте заполненный дневник, историю тренировок, фотографии и сведения о здоровье в репозитории, его обсуждениях или запросах на изменения.

## Где сохранять личные сведения

- **Claude / ChatGPT:** в личном проекте и резервной копии на вашем устройстве. Проверьте настройки обработки данных провайдера и общего доступа.
- **Локальная папка:** `personal/`, которую Git игнорирует. Пустые шаблоны отдельно, в `templates/`.

Правила игнорирования Git помогают избежать случайного добавления файлов. Они не шифруют данные, не удаляют уже опубликованное, не блокируют принудительное добавление и не управляют хранением у провайдера ИИ. Приватный проект не означает, что провайдер не обрабатывает и не хранит его содержимое.

В репозитории нет телеметрии, сервиса аккаунтов, облачной базы или автоматической отправки данных. Дополнительные программы Python работают с локальными файлами. Загружая файлы в приложение ИИ, вы передаёте их этому приложению своим действием.

Передавайте только нужные для работы сведения. Достаточно имени или псевдонима. Полная дата рождения, адрес, работодатель, идентифицирующие медицинские документы и чужие записи для знакомства не нужны. Учёт тела, питания и сведения о здоровье можно пропустить.

## Перед публикацией изменений репозитория

Выполните `python scripts/check_public.py` и просмотрите изменения. Проверка выявляет личные каталоги среди публикуемых файлов, неожиданные пути, распространённые признаки секретов и устаревшие или изменённые пакеты. Она не распознаёт любой личный факт в обычном тексте; просмотр человеком остаётся необходимым.

Сборка использует явный список общих источников. Она не читает `personal/`, выгрузки чатов или соседние папки. Если заполнить публичный шаблон личными сведениями, он всё равно может стать источником утечки: пользуйтесь личной копией.

При случайной публикации личных сведений прекратите распространение ссылки и удалите раскрытые данные, включая историю репозитория при необходимости. Замените раскрытые ключи доступа. Удаление файла новым коммитом не удаляет его прежние версии.
