# Дополнительные возможности после настройки

Сначала выполните [пошаговую настройку](../START-HERE.ru.md). Для обычных занятий достаточно инструкций проекта, одного справочника и личного дневника. [English](ADVANCED-OPTIONS.md).

## Справочник в формате JSONL

[agent.jsonl](../starter/ru/agent.jsonl) содержит те же общие методики, справочные материалы и исследования, что и справочник. Это наш формат загружаемого документа, а не автоматически распознаваемая настройка ChatGPT. Если приложение его принимает, можно использовать его вместо справочника, но инструкции проекта всё равно нужно вставить отдельно. Загружать оба файла не требуется.

## Исследования и расчётный анализ

Попросите: «Изучи, поможет ли это изменение моей цели; покажи источники и ограничения выводов». Для проверки актуальных источников тренеру нужен интернет-поиск. У сохранённых обзоров есть даты проверки; библиотека не обновляется непрерывно. Выводы остаются предложениями, пока вы не согласитесь изменить план.

Для расчётного разбора недели и статистической тенденции веса прикрепите [trainer-tools.zip](../starter/trainer-tools.zip) в сеансе, где доступно выполнение Python, и попросите применить его к актуальному дневнику. Сама загрузка ZIP не включает выполнение кода. Если его нет, используйте обычное обсуждение записей. [Техническое описание анализа на английском](ANALYTICS.md).

## Навык Claude или Claude Code

Если аккаунт Claude поддерживает пользовательские навыки, загрузите [personal-training-coach.zip](../starter/personal-training-coach.zip) через меню навыков и включите его для разговоров о тренировках. Он содержит общий справочник и инструменты анализа. Личный дневник храните отдельно. [Руководство Claude по навыкам](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

Пользователи Claude Code могут открыть репозиторий: корневой `CLAUDE.md` указывает на `.claude/skills/personal-training-coach/`. Codex использует `AGENTS.md`. Эти файлы предназначены для работы с репозиторием; в обычный проект Claude загружается отдельный полный файл из `starter/ru`.

## Личные локальные папки

Если помощник действительно может редактировать локальные файлы, используйте [режим папок, описание на английском](FOLDER-MODE.md). Выберите один основной личный дневник или рабочую папку; перед переходом между режимами согласуйте версии. Не записывайте личные данные в публичные шаблоны.

## Общение по-русски

[Русское руководство](../START-HERE.ru.md) использует переведённые инструкции и пустой дневник из `starter/ru`. Сформированные справочники содержат те же английские методики и исследования, что и основная версия, с русскими языковыми инструкциями. Разговор и свободные записи дневника ведутся по-русски. Служебные заголовки таблиц и значения сохраняют совместимость с общими инструментами анализа; тренер объясняет их, а не просит пользователя переводить.
