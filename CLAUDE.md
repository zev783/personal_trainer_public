# Personal trainer repository

For coaching, read the repository skill at [`.claude/skills/personal-training-coach/SKILL.md`](.claude/skills/personal-training-coach/SKILL.md). It is a self-contained Claude Code copy of the public coaching handbook, research library, blank notebook, and optional analysis tools. Use private records in `personal/` when local access is available, or the user's latest trainer notebook in chat. Never fill public starter files with personal information.

For repository maintenance, follow [AGENTS.md](AGENTS.md) and [docs/MAINTAINING.md](docs/MAINTAINING.md). Files under `.claude/skills/`, files under `starter/`, and `agent.jsonl` are generated by `python scripts/build_starter.py`; edit their named public sources and rebuild them. Never read or import a neighboring personal workspace unless the user explicitly requests it.
